# Feature docs

Each feature gets a markdown file in this folder. Register it in [../INDEX.md](../INDEX.md).

## Template

```markdown
# Feature name

**Status:** planned | in-progress | shipped

## Summary

One short paragraph.

## Related

- Schema: …
- API: …
- Client: …
- Linked features: …

## Behavior

…

## Open questions

- …
```

Docs in this repository describe the **SDK**. Do not document a specific host app, screen, or bundle ID.
